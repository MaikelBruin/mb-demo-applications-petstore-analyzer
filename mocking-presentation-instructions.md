# mocking presentation instructions

## introduction
Hi, I am giving a presentation about the importance of mocking for test automation engineers / software developers in
test. I want to discuss the following topics:
- what is mocking
- why should testers learn to mock
- how to mock

In my presentation I want to emphasize the following points:
- mocking can not only be used for unit tests, but also for integration tests and system tests
- mocking enables testing earlier in the SDLC and can therefore provide a faster feedback cycle
- mocking enables triggering edge cases involving external systems that would otherwise be more difficult to trigger
- mocking should be done with caution (don't mock things you want to include in your testing scope)
